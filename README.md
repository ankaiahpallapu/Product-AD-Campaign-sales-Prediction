# 📊 AD Campaign Performance Prediction

> **Machine Learning project for predicting product orders from advertising campaign characteristics.**

This project develops an end-to-end machine learning pipeline to predict **product orders** based on advertising campaign and product-related information.

The workflow covers data cleaning, exploratory data analysis, feature engineering, model comparison, hyperparameter optimization, model evaluation, explainability, model persistence, and deployment preparation with Streamlit.

---

## 🎯 Project Objective

The main objective is to build a regression model that can estimate the number of **orders generated by an advertising campaign**.

The project analyzes campaign-related variables such as:

* Campaign type
* Campaign level
* Product level
* Resource amount
* Email rate
* Product price
* Discount rate
* Campaign fee
* Hour resources

The target variable is:

**`orders`**

---

## 📁 Dataset

The project uses:

`products_campaign_sales.csv`

Dataset size:

* **731 observations**
* **11 columns**
* Numerical and categorical campaign features
* Target variable: `orders`

---

## 🔍 Project Workflow

### 1. Data Loading

The dataset is loaded using Pandas and inspected using:

* `head()`
* `info()`
* `describe()`

### 2. Data Cleaning

The preprocessing pipeline includes:

* Missing-value inspection
* Removing missing records
* Duplicate detection
* Duplicate removal
* Data validation

### 3. Exploratory Data Analysis

The project explores:

* Orders distribution
* Orders outliers
* Correlation between numerical variables
* Price vs. orders
* Discount rate vs. orders
* Campaign fee vs. orders
* Categorical feature distributions

Several visualizations are created using **Matplotlib** and **Seaborn**.

### 4. Feature Engineering

Feature preparation includes:

* Outlier treatment using percentile clipping
* Discount-rate scale correction
* Log transformation of skewed numerical variables
* Removing a feature with limited predictive value
* One-hot encoding categorical variables

### 5. Model Training

Multiple regression algorithms are compared:

* Linear Regression
* Ridge Regression
* Lasso Regression
* Support Vector Regression
* K-Nearest Neighbors
* Random Forest
* Gradient Boosting
* XGBoost

Models are evaluated using:

* **R²**
* **MAE**
* **RMSE**
* **Cross-validation R²**

### 6. XGBoost Optimization

XGBoost is further optimized using **Optuna**.

The hyperparameter search explores parameters including:

* `n_estimators`
* `max_depth`
* `learning_rate`
* `subsample`
* `colsample_bytree`
* `min_child_weight`
* `reg_alpha`
* `reg_lambda`

The notebook performs **30 Optuna trials** to identify a strong parameter configuration.

### 7. Model Evaluation

The final model is evaluated using:

* Actual vs. predicted plots
* Residual analysis
* Error distributions
* R²
* MAE
* RMSE
* Holdout-set performance
* Generalization gap analysis

A separate holdout set is used to estimate how well the model generalizes to unseen data.

### 8. Model Explainability

The project includes model interpretation using **SHAP** to investigate feature contributions and understand individual predictions.

### 9. Model Saving

The trained model and supporting preprocessing information are saved using:

```text
model_xgb.pkl
scaler.pkl
columns.pkl
```

### 10. Streamlit Application

A Streamlit application is prepared to allow users to enter campaign information and generate an estimated number of orders.

The application accepts campaign inputs such as:

* Email rate
* Campaign fee
* Price
* Discount rate
* Campaign type
* Campaign level
* Product level
* Resource amount

## 🚀 How to Run



Open:


After generating the model files:

